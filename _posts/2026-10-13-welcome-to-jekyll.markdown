## 让记录从简单开始

一篇文章可以只回答一个问题：遇到了什么，尝试了什么，最后理解了什么。先把内容写下来，再慢慢修订。

> 这里是一段引用示例。引用与正文保持相同的阅读节奏，用一条细线区分。

## 用 Markdown 写作

用 **粗体** 标记重点，用 *斜体* 补充语气，也可以加入列表：

- 记录问题发生的背景。
- 留下可以复现的步骤。
- 写下结论与尚未解决的疑问。

### 一段代码

```python
def hello(name):
    return f"Hello, {name}!"

print(hello("world"))
```

代码块会保留缩进，并在窄屏上横向滚动。
